# Chess Star

Self-contained 2D chess-themed mobile-style web app. The entire game lives in a single HTML file with inline CSS + JS. Backed by a small Express API for accounts/version/search.

## Structure
- `artifacts/chess-star/index.html` — the whole client app (UI, engine, AI, persistence, sockets, i18n)
- `artifacts/chess-star/vite.config.ts` — vite dev server config
- `artifacts/api-server/src/routes/` — Express routes (`health`, `account` — version/search/friend-request)
- `attached_assets/ChessStar_v.0.01_1777212252657.html` — original untouched backup
- `attached_assets/ChessStar_v.0.04_1777279447683.html` — previous published backup
- `attached_assets/ChessStar_v.0.05.html` — current handoff backup

## Persistence (localStorage keys)
- `chessstar_profile` — `{name, color}`
- `chessstar_icon`    — selected emoji (1 of 20, gated by total wins)
- `chessstar_lang`    — `'en' | 'ro' | 'ru'`
- `chessstar_skins`   — per-piece skin id map
- `chessstar_theme`   — `'dark' | 'light'`
- `chessstar_wins`, `chessstar_trophies`, `chessstar_streak`, `chessstar_recent`, `chessstar_replays`
- `claimed_wins`, `claimed_trophies` — milestone claim state
- `acct_code`, `acct_name` — login identity
- 13-char save code: `#NNNNNNNNCHH_` (8-char name, 1 color index, 2 hex skin bitmask, pad)

## Skins
- `classic` — flat 2D web style (unicode chess silhouettes, default)
- `wood` — realistic 3D ivory shapes in wood tones

## Events
- `lps`     — Last Piece Standing (6 or 4 players, poison ring)
- `classic` — Classic Chess (1v1, full rules) — now with AI opponent
- `qoc`     — Queens On Color (checkers/dame with bishop promotion + 2 wheels of fortune)
- `gts`     — Grind The Safe (drain enemy safe HP) — now with AI opponent

## Game modes (v0.05)
- `1v1` / `2v2` / `4v4` — selectable on every event
- 2v2 / 4v4 trigger the pre-game piece picker (2v2 = pick 2 pieces, 4v4 = pick 1)

## Piece progression (v0.05)
- Only Pawn unlocked at start
- Rook 5W, Knight 10W, Bishop 15W, Queen 25W, King 50W (W = total wins)
- Skins also locked behind owning the parent piece

## Profile icons (v0.05)
- 20 emoji icons; first 3 unlocked, the rest gated by win counts
  (1, 3, 5, 8, 10, 15, 20, 25, 35, 50, 65, 80, 100, 125, 150, 200, 300)

## AI (v0.05)
- Classic + GTS now have an AI opponent (~3 s think time)
- Material + center-control + mobility scoring with 1-ply consequence check at higher levels
- Difficulty drawn from existing `aiLevel('enemy')` (1..10)

## i18n (v0.05)
- English / Romanian / Russian — switch in Settings → Language
- All `[data-i18n="..."]` strings translated via the `I18N` table at the bottom of the script

## Friends / multiplayer (v0.05)
- Friend search by name (fuzzy) — `/api/account/search?q=...`
- Friend identity = login code; you add by name (server resolves to code)
- Invite popup shows event + mode with Accept / Decline; decline notifies sender
- In-match team chat (text + 8 quick emoji)
- Max team size 4 (only valid sizes: 2 / 4)

## Backend (v0.05)
- `GET  /api/healthz`              — health check
- `GET  /api/version`              — `{latest, required}` for client gate
- `POST /api/account/upsert`       — register a player code+name
- `GET  /api/account/search?q=`    — fuzzy name search (in-memory)
- `POST /api/account/friend-request` — queue a friend request

## Dev hash routes
`#pieces`, `#piece-Q`, `#skins`, `#events`, `#settings`, `#qoc`

## Workflows
- `artifacts/chess-star: web`              — vite dev server bound to `$PORT`
- `artifacts/api-server: API Server`       — Express on `:8080`
- `artifacts/mockup-sandbox: Component Preview Server` — for canvas mockups
